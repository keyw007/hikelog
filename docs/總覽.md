## 二、登山行程紀錄 App

**目前版本：v0.5.0**（App 列表頁最下方可看版本與更新紀錄）

### 安裝到 iPhone
1. 用 **Safari** 打開 https://keyw007.github.io/hikelog/
2. 點「分享」→「加入主畫面」
3. 從主畫面圖示開啟。第一次要在有網路的地方開，之後就能離線使用。

> 一定要從主畫面圖示使用。刪除主畫面圖示會連同資料一起刪除。

Android：用 Chrome 開網址 → 選單 →「安裝應用程式」。

### 功能
- 每次登山建立一筆獨立行程（類型：一般登山、百岳、日本登山、長程健行、其他）
- 一鍵「記錄出發／抵達／離開」，自動寫入手機時間；按錯可復原
- 自動計算：各站休息、路段行走、累積經過、實際行走、累積休息
- 每站可改名稱、備註、手動修正時間，標記天氣、隊員體力
- 按下時記錄一次 GPS 座標與海拔（不在背景追蹤，省電）
- 快速標記：水源、岔路、危險地形、收訊點、營地、廁所、觀景、路況不佳
- 夜間紅光模式、大字模式（右上角 Aa）
- 行程報告：各段行走、爬升下降、垂直速度、沿途狀況，可分享文字
- 路段比較：同一條路線站名相同時，自動和上次比較
- 個人統計與百岳清單：完整 100 座、依路線分組、自動辨識站名與別名、可補登以前的紀錄
- 匯出 CSV、複製表格（可貼到 Excel／Google 試算表／Notion）
- 備份全部（JSON）與還原；列表頁顯示上次備份時間，行程結束時提醒備份

### 計算方式
| 項目 | 算法 |
|---|---|
| 各站休息 | 該站離開 − 該站抵達 |
| 路段行走 | 本站抵達 − 上一站離開 |
| 累積經過 | 最後時間（進行中為現在）− 出發時間 |
| 累積休息 | 各站休息加總 |
| 實際行走 | 累積經過 − 累積休息 |

### 資料保存
- 目前資料只存在各自手機的 App 裡，多人使用互不干擾，但**換手機會不見**。
- 換手機前：列表頁「備份全部（JSON）」→ 分享選單「儲存到檔案」→ iCloud Drive；新手機用「從備份還原」。

### 每日頁怎麼填
- **類型**：行走、休息、營地、交通。行走和休息計入行動時間，營地和交通不計入。
- **花費時間的順序**：自訂時間 → 上河時間 × 速度係數 → 地形估算 → GPX 估算 × 速度係數。估算的時間以橙色斜體顯示。
- **地形條件**（最右邊）：選條件後，用距離、爬升、下降依「時間參數」算出時間；適合沒有 GPX、沒有上河，或叢穿、雪季、困難地形的路段。
- **停留 (分)**（最右邊）：在某點短暫停留（喝水、會師、拍照）直接填這裡，會算出出發時間並計入休息；起床拔營、午餐、紮營取水仍獨立一列。
- **上坡 %、下坡 %**：自動計算，超過 17% 標橘、超過 30% 標紅。
- **出發時間**填在 N1，預計抵達時間會自動往下算。
- **座標**：先選座標系（TWD97／TWD67／WGS84），再填座標，會自動換算成 TWD97 與經緯度，並產生地圖連結。
- **勾選欄**：水源、通訊點、營地、撤退點，會彙整到總覽。
- **關門時間**（最右欄）：幾點前沒到就折返；預計抵達晚於關門時間會標紅。
- 日出前、日落後抵達的列自動加灰底。
- 增加天數：複製 D5 分頁、改名 D6、把 B1 改成 6，再到總覽三個表格各加一列。

### 顏色說明
| 顏色 | 意思 |
|---|---|
| 深綠標題 | 自行填寫的欄位 |
| 灰色標題 | 自動計算，請勿修改 |
| 黃底 | 需要填寫的設定值 |
| 淺藍底的列 | 休息 |
| 灰底的列 | 日出前或日落後抵達 |
| 紅字預計抵達 | 日落前 30 分鐘內才抵達，或晚於關門時間 |

### 行動糧與飲水計算
- 路線常數 ＝ 1.8 × 行動時間 (h) ＋ 0.3 × 距離 (km) ＋ 10 × 爬升 (km) ＋ 0.6 × 下降 (km)
- 消耗熱量 (kcal) ＝（體重 ＋ 負重）× 路線常數；失水量 (ml) 數值約等於消耗熱量
- 行動糧熱量 ＝ 消耗 × 補給比例（預設 70%），當天有午餐時扣掉一份麵包
- 預設行動糧配置（依熱量）：餅乾方塊酥 45%、果乾軟糖羊羹 20%、能量棒 15%、能量膠 10%、堅果巧克力 10%
- 體重、背包重量留空時，熱量相關欄位顯示「請填體重」

### 座標換算
- TWD97 ↔ WGS84：橫麥卡托投影公式（中央經線 121°），誤差小於 1 公尺
- TWD67 → TWD97：台灣常用近似公式，誤差約 1～3 公尺（兩者相差約 850 公尺，請確認來源）
- 只適用台灣本島；澎湖、金門、馬祖不適用

### 在山上離線查看
手機 Google 試算表 App → 檔案「⋯」→ 開啟「可離線使用」。

## 四、行程圖產生器

網址：https://keyw007.github.io/hikelog/itinerary.html

### 使用方式
1. 在試算表打開某一天（例如 D2），按 Ctrl+A 全選，再按 Ctrl+C（Mac 用 ⌘）。
2. 到產生器頁面，點框框後按 Ctrl+V。D0～D5 可以連續貼，每天一張圖。
3. 按「複製圖片」到 Word 貼上；或「下載 PNG」再從 Word「插入 → 圖片」。

建議用電腦的 Chrome 或 Edge。

### 圖片內容
- 格式比照行程計劃書附件二：青色欄位標題、黃色日期與路線列、藍色粗體標示休息／營地／交通、橘色小計與備註
- 欄位：抵達時間、出發時間（有停留時才出現）、關門時間、花費時間、累積時間、爬升、下降、公里數、海拔、地點、上河時間、備註
- 小計：行走時間、休息時間、總爬升、總下降、總距離、日落前餘裕；填了體重時加上行動糧、碳水目標、需水
- 灰底標示摸黑路段，紅字標示關門時間，圖下方附圖例
- 可勾選開關：備註欄、地點旁標示、行動糧與需水、累積時間、摸黑灰底
- 輸出 2 倍解析度，寬度在 Word 直式 A4 一頁內

## 五、計劃書產生器（Apps Script）

在試算表上方加一個「計劃書」選單，一鍵產生 Google 文件和 Word（.docx）。

### 安裝（每份試算表一次；裝在空白範本，之後建立副本都會帶著）
1. 試算表 →「擴充功能」→「Apps Script」
2. 刪掉預設內容，貼上 https://github.com/keyw007/hikelog/blob/main/apps-script/計劃書.gs 的全部內容 → 儲存
3. 重新整理試算表 →「計劃書」→「產生計劃書（Google 文件＋Word）」
4. 第一次要授權：選帳號 →「進階」→「前往（不安全）」→「允許」

### 計劃書內容
- 標題、活動日期、集合、入山／出口、車輛、參加人員（含緊急聯絡人）、費用、申請編號、隊伍分工
- 預計下山時間、山難管制時間（預計下山＋緩衝小時數，預設 24）
- 留守人、回報方式（inReach 為主，有訊號用 LINE）、留守人職責、MapShare
- 公裝分工表（自己帶／幫別人背／交給別人背）與公裝重量表
- 行程路線（從每日頁帶入，不用重打）、伙食、水源、營地、帳篷、公裝分配、急救包、通訊點、無線電、撤退方案（每天）、求援流程、團隊公約、注意事項
- 附件一 個人裝備檢查表；附件二 每日行程表（摸黑灰底、關門紅字、估算時間、累積時間）；附件三 水源／營地／通訊點／撤退點座標
- 頁尾隱私提醒；每次產生都是新檔，不覆蓋

### 每次出隊要記得改
- MapShare 密碼
- 成員、費用、公裝、伙食
- 每日撤退方案

## 六、更新與維護

### 修改 App 後如何上線
1. 修改 repository 裡的 `index.html` 或 `itinerary.html`
2. 修改 App 時，把 `sw.js` 第一行的 `VERSION` 改成新版號（例如 `hikelog-v0.6.0`），並更新 `index.html` 裡的 `APP_VERSION` 和 `CHANGELOG`
3. 推上 GitHub，約 1 分鐘後生效
4. 手機下次連網開啟 App 會自動更新；沒更新就把 App 完全關閉再開

### Repository 檔案
| 檔案 | 說明 |
|---|---|
| index.html | 登山行程紀錄 App 主程式 |
| itinerary.html | 行程圖產生器 |

| README.md | 部署與使用說明 |
| apps-script/計劃書.gs | 計劃書產生器（貼到試算表的 Apps Script） |
