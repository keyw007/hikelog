# 計劃書產生器（Apps Script）

把行程規劃試算表一鍵轉成 Google 文件與 Word（.docx）計劃書。

## 安裝（每份試算表做一次；裝在空白範本裡，之後「建立副本」都會帶著）

1. 開啟試算表 →「擴充功能」→「Apps Script」
2. 刪掉預設的 `function myFunction() {}`，把 `計劃書.gs` 全部內容貼上
3. 按「儲存」（磁碟圖示），關掉 Apps Script 分頁
4. 重新整理試算表，上方會出現「計劃書」選單
5. 「計劃書」→「產生計劃書（Google 文件＋Word）」
6. 第一次會要求授權：選自己的 Google 帳號 →「進階」→「前往（不安全）」→「允許」
   （這是自己寫的腳本還沒經過 Google 審核，所以會顯示警告）

## 會讀哪些分頁

| 分頁 | 用途 |
|---|---|
| 計劃書資料 | 活動資訊、分工、留守人、MapShare、各種說明；A 欄名稱不要改 |
| 成員 | 姓名、手機、緊急聯絡人 |
| 費用 | 每人金額自動計算 |
| 公裝 | 公裝分配與每人背負重量 |
| 伙食 | 每天三餐 |
| 裝備清單 | 附件一 |
| 固定內容 | 留守人職責、團隊公約、急救包、求援流程等 |
| D0～Dn | 附件二每日行程、附件三座標（勾選水源／營地／通訊點／撤退點的列） |

## 產出

- Google 文件與 .docx 都存在試算表所在的資料夾，檔名加上產生時間，不會覆蓋舊檔
- A4 直式；主表＋附件一 裝備檢查表＋附件二 每日行程＋附件三 座標
- 頁尾有隱私提醒（內容取自「固定內容」）
