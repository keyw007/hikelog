# GPX 匯入（參考實作）

把 GPX 軌跡與航點轉成試算表每日頁的資料：距離、爬升、下降、海拔、座標、估算時間、實際紀錄時間。這是匯入嘉明湖・新康橫斷那次用的程式，`specs.py` 是那條路線專用的對照表（GPX 航點 → 計劃書地點、上河時間）。換新路線時，以這份為範本改寫 `specs.py`。

| 檔案 | 內容 |
|---|---|
| `gpxlib.py` | 讀 GPX（`GPX_DIR` 環境變數指定資料夾，檔名含 `-D1_` 這種天數標記）、找航點在軌跡上的位置、距離計算 |
| `build.py` | 逐段計算距離、爬升下降（7 點平滑）、Tobler 估算時間，並用當天的上河時間校正；多段共用一個上河時間時依坡度分配 |
| `specs.py` | 每天的地點清單：`G()` 對應 GPX 航點、`R()` 休息／營地列、`PL()` 只有上河時間的地點 |

計算方式：
- Tobler：v = 6·exp(−3.5·|坡度＋0.05|) km/h
- 實際紀錄：GPX 原隊伍兩點間的經過時間，扣掉 5 分鐘以上、移動不到 30 m 的停留；間隔超過 3 小時的不算
- 軌跡沒有高度時，用航點高度在軌跡上內插
